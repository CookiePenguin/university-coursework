## 🗂️ Структура репозитория

```text
university-coursework/
├── semester-7/
│   ├── user-interface-development/
│   │   ├── practical-work-1/
│   │   └── practical-work-2/
│   └── agricultural-statistics/
│       └── practical-work-3/
├── .gitignore
└── README.md
```

Каждая практическая работа размещается в отдельном каталоге и по возможности содержит собственный `README.md` с описанием задания, используемых технологий и инструкцией по запуску.

## 🛠️ Используемые технологии

В зависимости от дисциплины и задания могут использоваться:

- **HTML5** — структура веб-страниц.
- **JavaScript** — программирование и интерактивность.
- **Python** — обработка и анализ данных.
- **Git** — контроль версий.
- **GitHub** — хранение и публикация исходного кода.

## 📌 Принципы организации

- Каждая дисциплина располагается в отдельном каталоге.
- Каждая практическая работа имеет собственную папку.
- Названия каталогов и файлов используют единый стиль именования.
- README-файлы содержат описание соответствующей работы.
- Изменения сохраняются в Git и публикуются в удалённом репозитории.

## 🎯 Цель репозитория

Систематизировать учебные материалы, закреплять практические навыки программирования, отслеживать прогресс и сохранять результаты выполненных работ в одном месте.
