## 📖 О проекте

В рамках данной практической работы проводится **дискриминантный анализ** на основе классического датасета Рональда Фишера (Fisher, 1936) — одного из самых известных наборов данных в истории статистики.

**🎯 Цель анализа:** Изучить дискриминацию между тремя типами ирисов (*Setosa*, *Versicolor*, *Virginica*) на основе четырёх морфометрических признаков:
- Длина и ширина чашелистиков (Sepal)
- Длина и ширина лепестков (Petal)

## 🐧 Мотивация: Почему Python, а не STATISTICA?

Методические указания к работе предполагают использование пакета **STATISTICA** и файла `Irisdat.sta`. Однако на современных Linux-системах (Ubuntu) работа с этим ПО крайне затруднена или невозможна.

✨ **Решение:** Полная реализация всех этапов анализа на **Python** с автоматической генерацией итогового отчёта в формате `.docx`, строго следуя структуре методических указмй. Никакого ручного копирования цифр и вставки графиков!

## 🔬 Что делает скрипт?

Скрипт `generate_report.py` выполняет **весь пайплайн** практической работы, включая:

### 1️⃣ Описательные статистики
- 📈 Средние значения и число наблюдений для каждой совокупности
- 📊 Гистограммы частот распределения с наложением нормального закона
- 📉 Категоризированные диаграммы размаха (Boxplots) с отображением `Mean/SD/1.96*SD`
- 🔗 Диаграммы рассеяния для анализа корреляций между переменными

### 2️⃣ Пошаговый дискриминантный анализ
- 🧮 Расчёт **Λ Уилкса (Wilks' Lambda)** на каждом шаге включения переменных
- 📐 Вычисление F-статистик для включения/исключения переменных
- 🔍 Анализ **толерантности** (1 - R²) для оценки избыточности предикторов
- 📋 Частичная статистика Уилкса для оценки вклада каждой переменной

### 3️⃣ Канонический анализ
- 🧬 Вычисление собственных значений (корней) и объяснённой дисперсии
- ⚖️ Стандартизованные коэффициенты канонических переменных
- 📊 Визуализация канонических корней (Root 1 vs Root 2)
- 🎯 Анализ средних канонических переменных для интерпретации функций

### 4️⃣ Классификация
- 🎲 Построение **матрицы классификации** (с учётом априорных вероятностей)
- 📏 Вычисление **расстояний Махаланобиса** до центроидов групп
- 🎯 Расчёт апостериорных вероятностей принадлежности к классам
- ✅ Оценка общей точности классификации
