# Практическая работа № 7 — Дискриминантный анализ

**Дисциплина:** Многомерные статистические методы  
**Тема:** Дискриминантный анализ

## 📚 Описание работы

В рамках практической работы выполнен дискриминантный анализ набора данных **Iris**, содержащего измерения трёх видов ирисов: Setosa, Versicol и Virginic.

Цель работы — изучить возможности многомерных статистических методов для разделения объектов на группы, определить вклад исследуемых признаков в дискриминацию и оценить качество классификации наблюдений.

Для анализа используются четыре характеристики цветков:

- длина чашелистика (Sepal length);
- ширина чашелистика (Sepal width);
- длина лепестка (Petal length);
- ширина лепестка (Petal width).

В качестве основного метода классификации применяется линейный дискриминантный анализ (LDA).

## 📚 Выполненные задания

### 1. Просмотр описательных статистик

Выполнен первичный анализ исходного набора данных:

- рассчитаны средние значения признаков для каждого вида ирисов;
- определено количество наблюдений в каждой группе;
- построены гистограммы распределения признаков;
- построены диаграммы размаха (Boxplot);
- построена диаграмма рассеяния для сравнения длины чашелистика и лепестка.

Полученные графики позволяют оценить распределение признаков и визуально определить различия между исследуемыми группами.

### 2. Пошаговый дискриминантный анализ

Рассмотрены показатели, используемые для оценки разделяющей способности переменных:

- лямбда Уилкса;
- статистика F-включить;
- толерантность;
- частичная лямбда Уилкса.

Проведено сравнение признаков по их вкладу в разделение групп.

По результатам анализа наибольшую разделяющую способность демонстрирует длина лепестка (Petal length). Существенный вклад также вносит ширина лепестка (Petal width).

### 3. Канонический анализ

Выполнен линейный дискриминантный анализ с построением канонических функций.

В рамках задания:

- рассчитаны канонические значения;
- рассмотрены собственные значения и доли объяснённой дискриминантной дисперсии;
- получены стандартизованные коэффициенты канонических переменных;
- рассчитаны средние значения канонических функций для каждой группы;
- построена диаграмма рассеяния канонических значений.

Результаты позволяют оценить, насколько хорошо канонические функции разделяют три вида ирисов.

### 4. Классификация

Выполнена классификация наблюдений с использованием модели LDA.

Дополнительно:

- сформирована матрица классификации;
- рассчитана доля правильно классифицированных наблюдений;
- рассчитаны расстояния Махаланобиса до центроидов трёх групп для первых пяти наблюдений.

Расстояния Махаланобиса используются для оценки близости наблюдения к соответствующим группам.
