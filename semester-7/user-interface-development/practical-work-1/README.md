# Практическая работа № 1 — Основы JavaScript

Учебная практическая работа по изучению основ языка программирования JavaScript. В ходе выполнения рассматриваются типы данных, арифметические операции, работа со строками, условные конструкции и циклы.

## 📚 Содержание работы

### 1. Типы данных и арифметические операции
- Объявление и изменение переменных с помощью `let`.
- Определение типов данных с помощью `typeof`.
- Преобразование типов: `String()` и `Number()`.
- Выполнение арифметических операций.
- Использование методов объекта `Math`.
- Особенности вычислений с числами с плавающей точкой.
- Работа с типом `BigInt`.
- Обработка ошибок при операциях с несовместимыми типами.

### 2. Работа со строками
- Удаление лишних пробелов с помощью `trim()`.
- Интерполяция строк с использованием шаблонных литералов.
- Определение длины строки.
- Использование символов переноса строки и табуляции.
- Повторение строк и изменение регистра символов.
- Извлечение подстрок.
- Поиск и замена текста.
- Обращение к символам строки по индексу.

### 3. Условные конструкции
- Использование `if` и `else`.
- Выбор ветви выполнения с помощью `switch`.
- Сравнение значений с использованием `==` и `===`.

### 4. Циклы
- Использование циклов `for`, `while` и `do...while`.
- Вычисление суммы чисел.
- Пропуск итераций с помощью `continue`.
- Прерывание цикла с помощью `break`.
- Перебор символов строки через `for...of`.
- Создание таблицы умножения с помощью вложенных циклов.

## 🚀 Запуск работы

Для запуска не требуются установка дополнительных зависимостей или сборка проекта.

1. Открой файл `index.html` в браузере.
2. Открой инструменты разработчика браузера.
3. Перейди во вкладку **Console** («Консоль»).
4. Просмотри результаты выполнения JavaScript-кода.

В Firefox и Chrome на Linux консоль обычно можно открыть сочетанием клавиш `Ctrl + Shift + J`. Также можно нажать `F12` и выбрать вкладку **Console**.
