# Практическая работа № 4 — Объекты и массивы объектов в JavaScript

Практическая работа посвящена созданию и обработке объектов в JavaScript. В ходе выполнения разработана модель каталога товаров, реализованы поиск и фильтрация элементов, преобразование массива объектов и вычисление средней стоимости товаров.

Результаты выполнения программы отображаются в отдельном блоке «Вывод программы» на HTML-странице и одновременно выводятся в консоль браузера.

## 📚 Выполненные задания

### Задание 1. Создание массива объектов

Создан массив `products`, содержащий семь объектов товаров.

Каждый товар имеет следующие свойства:
- `id` — уникальный идентификатор;
- `name` — название товара;
- `price` — цена;
- `category` — категория товара;
- `available` — наличие товара;
- `rating` — рейтинг.

Для демонстрации предусмотрены разные категории товаров, а также доступные и недоступные позиции.

### Задание 2. Вывод списка товаров

Реализована функция `showProducts(products)`, которая выводит информацию о товарах с помощью метода `forEach()`.

Для каждого элемента формируется строка с основными характеристиками товара.

### Задание 3. Поиск товара по идентификатору

Создана функция `findProductById(products, id)`, использующая метод `find()`.

Функция возвращает объект найденного товара. Если товар с указанным идентификатором отсутствует, возвращается `null`.

### Задание 4. Фильтрация товаров по категории

Реализована функция `getProductsByCategory(products, category)` на основе метода `filter()`.

Она возвращает новый массив товаров, относящихся к указанной категории.

### Задание 5. Получение доступных товаров

С помощью метода `filter()` создан массив `availableProducts`, содержащий только товары, доступные для покупки.

### Задание 6. Преобразование массива товаров

Метод `map()` используется для создания массива `productCards`.

Каждый элемент содержит строковое представление товара в формате «Название — цена руб.».

### Задание 7. Вычисление средней цены

Создана функция `getAveragePrice(products)`, использующая метод `reduce()` для вычисления средней стоимости товаров.

Предусмотрена обработка пустого массива: в таком случае функция возвращает `0`.

### Задание 8. Изменение доступности товара

Реализована функция `toggleAvailability(products, id)`, которая находит товар по идентификатору и переключает его свойство `available`.

Для демонстрации функция вызывается для товара с идентификатором `2`. После изменения состояния обновлённый каталог выводится повторно.

## 🚀 Запуск

1. Откройте файл `index.html` в браузере Firefox.
2. Дождитесь выполнения JavaScript-кода.
3. Результаты выполнения заданий появятся в блоке «Вывод программы» на странице.
4. Для очистки отображаемых результатов нажмите кнопку «Очистить вывод».
5. При необходимости откройте инструменты разработчика Firefox сочетанием клавиш `Ctrl + Shift + K`, чтобы посмотреть сообщения в настоящей консоли браузера.
