# Практическая работа № 2 — Функции

Учебная работа по изучению функций в JavaScript. В рамках практического занятия рассматриваются способы объявления функций, передача аргументов, возврат значений и работа с произвольным количеством параметров.

## 📚 Выполненные задания

### 1. Обычная функция
Реализована функция `calculateRectangleArea(width, height)`, вычисляющая площадь прямоугольника по его ширине и высоте.

### 2. Function Expression
Создана функция `average`, вычисляющая среднее арифметическое трёх чисел. Функция присваивается переменной с помощью функционального выражения.

### 3. Стрелочная функция
Реализована функция `averageArrow`, выполняющая вычисление среднего арифметического трёх чисел с использованием синтаксиса стрелочных функций.

### 4. Параметр по умолчанию
Создана функция `greet(name = "Пользователь")`, возвращающая приветствие. Если имя не передано, используется значение по умолчанию.

### 5. Произвольное количество аргументов
Реализована функция `sum(...numbers)`, вычисляющая сумму переданных чисел. Для обработки массива аргументов используется метод `reduce()`.

4. Просмотри результаты выполнения заданий.

Для Firefox на Linux также можно использовать сочетание клавиш `Ctrl + Shift + K`.
