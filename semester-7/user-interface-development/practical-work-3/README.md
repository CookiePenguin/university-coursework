# Практическая работа № 3
## Классы и объекты в JavaScript

### Цель работы

Изучение классов и объектов в JavaScript, конструкторов, методов, свойств, геттеров и сеттеров, статических методов, наследования и оператора `instanceof`.

### Выполненные задания

1. **Класс User** — создание класса с именем и возрастом, конструктором и методом `showInfo()`.
2. **Класс Counter** — реализация счётчика с методами увеличения, уменьшения и сброса значения.
3. **Класс Product** — создание товаров с названием, ценой и геттером `info`.
4. **Setter price** — проверка цены товара и запрет на сохранение отрицательных значений.
5. **Статический метод compare()** — сравнение двух товаров по стоимости.
6. **Наследование** — создание класса `Admin`, наследующего класс `User`, переопределение метода `showRole()` и реализация `deleteUser()`.
7. **Оператор instanceof** — проверка принадлежности объектов к классам и родительским классам.
8. **Класс Button** — реализация кнопки с управлением активностью и подсчётом нажатий.

### Структура проекта

- `index.html` — HTML-страница для запуска программы.
- `script.js` — реализация всех восьми заданий.
- `README.md` — описание практической работы.

### Используемые технологии

- HTML5
- JavaScript (ES6+)

### Запуск

1. Открыть файл `index.html` в браузере.
2. Открыть консоль разработчика клавишами `Ctrl + Shift + K` в Firefox.
3. Посмотреть результаты выполнения заданий в консоли.
