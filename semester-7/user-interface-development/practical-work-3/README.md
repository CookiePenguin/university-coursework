# Практическая работа № 3 — Классы и объекты

Учебная работа по изучению классов и объектов в JavaScript. В рамках практического занятия рассматриваются создание классов и экземпляров, конструкторы, методы, геттеры и сеттеры, статические методы, наследование и проверка принадлежности объектов к классам.

## 📚 Выполненные задания

### 1. Класс User
Создан класс `User` с конструктором, принимающим имя и возраст пользователя. Реализован метод `showInfo()`, возвращающий строку с информацией о пользователе. Созданы два экземпляра класса.

### 2. Класс Counter
Реализован класс `Counter`, представляющий счётчик с начальным значением `0`. Добавлены методы:
- `increment()` — увеличение значения на единицу;
- `decrement()` — уменьшение значения на единицу;
- `reset()` — сброс значения до нуля.

### 3. Класс Product и getter
Создан класс `Product` с названием и ценой товара. Реализован геттер `info`, возвращающий информацию о товаре в формате «Название — цена руб.».

### 4. Setter для цены товара
Добавлен сеттер `price(value)`, проверяющий передаваемое значение. Если цена отрицательная, выводится сообщение об ошибке, а прежнее значение сохраняется.

### 5. Статический метод compare()
Реализован статический метод `Product.compare(product1, product2)`, сравнивающий стоимость двух товаров и возвращающий название более дорогого товара. Также предусмотрена обработка случая одинаковой стоимости.

### 6. Наследование классов
Создан класс `Admin`, наследующий класс `User`. Добавлен метод `deleteUser()`, а метод `showRole()` переопределён для отображения роли администратора.

### 7. Оператор instanceof
Выполнена проверка принадлежности объектов к классам `User` и `Admin` с помощью оператора `instanceof`. Проверено влияние наследования на результаты проверки.

### 8. Класс Button
Создан класс `Button`, хранящий текст кнопки, состояние активности и количество нажатий. Реализованы методы:
- `click()` — обработка нажатия, если кнопка активна;
- `disable()` — отключение кнопки;
- `enable()` — включение кнопки;
- `showInfo()` — вывод информации о кнопке.

Проверена работа кнопки при включении и отключении, включая попытку нажатия в неактивном состоянии.
